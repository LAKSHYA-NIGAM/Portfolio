# 💼 Portfolio Website — Lakshya Nigam

This is my personal **portfolio website**, created to showcase my skills, projects, and experience in web development and computer science.

The website is designed with a clean and modern user interface, built using **HTML, CSS, and JavaScript**. It serves as my digital presence and helps me connect with recruiters, collaborators, and fellow developers.

## 🔗 Live Demo  
👉 [https://lakshyanigamportfoliowebsite.netlify.app](https://lakshyanigamportfoliowebsite.netlify.app)

- Fully responsive and modern UI  
- About Me, Projects, Skills, and Contact sections
